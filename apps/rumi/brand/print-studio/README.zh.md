# Print Studio

[English](README.md) | 中文

为 Rumi 的 3D 打印工作流提供环境检测和 Bambu Lab 配置引导。

Print Studio 检查以下三项配置。

- 是否已安装 Bambu Studio？
- 是否包含 H2D 配置文件？
- 是否已配置打印机，并且可通过局域网访问？

主机通过 SSDP 发现打印机，并提供配置状态、Bambu 账号登录、网格查看器路由和智能体工具。登录后获取已绑定打印机的访问码，用于监控状态。Print Studio 卡片位于**插件 → 内置插件设置**。内置的[配置技能](skills/print-studio-setup/SKILL.md)和 [FDM 设计技能](skills/fdm-design/SKILL.md)分别指导打印机配置和模型设计。

打印机 IP 和序列号存储在 `$DSH_HOME/print-studio/printer.json` 中，仅所有者可访问。局域网访问码通过 `ctx.credentials` 存储为 `BAMBU_LAN_ACCESS_CODE`；它不会返回给客户端，也不会写入配置补丁。

[打印机感知技能](skills/inspect-printer/SKILL.md)将实时状态工具和已安装的机器配置用于打印机相关决策，保留未知读数，并要求打印空间具有明确来源。

### 技能提醒

配置的凭据可用时，Print Studio 使用 Baseten Bison 检查已完成的步骤，适用于任何主模型提供商。整个 Print Studio 同时只运行一个检查请求。每个轮次可以排队等待一次检查，期间的新进展会合并到该检查。请求包含最新用户请求和可见智能体文本的有限摘录、当前任务计划、近期工具操作的描述与结果，以及变更后的 USD 模型及其区域表状态。Print Studio 将 shell 命令、原始工具输出、附件、模型文件和完整会话历史保留在本地。

Print Studio 优先使用结构化工具错误，也能识别以文本报告状态的 Bash 工具结果中的失败标记。

Bison 的每个问题都根据这份执行上下文判断是否需要发出特定提醒。区域问题检查智能体是否在区域表尚未完成时继续处理其他事项。回复问题检查可见文本是否需要精简。肯定结果可在主智能体的下一步进行引导，每项检查在每轮最多发出一次提醒。Print Studio 确认轮次仍在运行，并检查被标记的模型版本是否仍需区域表。提醒要求智能体继续处理当前请求，并为最终保留的已保存版本命名区域。轮次结束钩子在固定时限内等待尚未完成的检查。轮次结束或取消时会丢弃剩余检查。智能体文本照常流式输出，可能先于提醒出现。

在 Print Studio 插件配置中设置 `skillReminders.enabled: false` 可关闭检查。默认值为 `credential: BASETEN_API_KEY`、`everySteps: 1`、`timeoutMs: 2000`、`threshold: 0.8`、`maxTextChars: 4000` 和 `maxModels: 16`。设置 `everySteps: 2` 可每两步检查一次，并在结束钩子检查最后一步。自定义凭据通过凭据服务保存。

## 打印布局

活动实体部件必须分开打印后组装，并保留声明的旋转或滑动功能。智能体按照[分开打印要求](skills/printable-joints/SKILL.md#separate-printing-for-moving-parts)设计可组装的连接结构并说明组装顺序。旧的组装状态打印活动模型仍可查看，但在重新设计前不能发布、通过验证或准备打印。现有模型和脚本参见[迁移说明](upgrade-guide/separate-moving-parts/README.zh.md)。

在标准 USD 模型预览中选择 **安排打印**，即可将实体部件放到打印板上。**返回模型** 恢复已保存的模型及其运动控件。分开制造的部件单独放置，包括组装后通过固定连接相连的部件。旧的静态原位打印组保持整体。多部件模型缺少制造声明时，必须先修正模型才能排列。自动排列尝试轴对齐方向，优先降低高度，并在不改变比例的情况下添加打印板。它不选择支撑，也不保证可打印性。

拖动部件调整板上位置。所选部件显示轮廓。**撤销** 保留最多 32 次更改；**自动排列** 重新放置部件。包围矩形重叠、间距不足、超出打印板或过高都会阻止导出。完成编辑后，系统会在项目旁自动为每个模型原子保存独立的摆放信息。保存按顺序执行，并合并排队的编辑；选择部件或打印板不会写入布局。保存失败时保留草稿并提供 **重试保存**。返回模型、切换模型和打开切片软件会等待当前保存完成。保存的布局必须匹配源内容、查看器变换和打印板尺寸；模型更改后提供新排列供检查。无法读取的保存状态保持不变，直到用户明确开始新布局。

**在 Bambu Studio 中打开此板** 将选中的打印板导出为标准 3MF 文件，存放于新的私有 `.rumi-print-*` 项目文件夹。每个可打印部件都是可独立选择的对象，并保留比例、朝向和相对位置。纯色材质按面保存，同一网格可以包含多种颜色。在 Bambu Studio 的颜色导入窗口中将颜色映射到耗材。在 Bambu Studio 2.8.2 中，如果提示仅加载几何数据，请选择**确定**。打印前请检查打印板、支撑和切片。此操作不会发送打印任务。启动失败时保留导出文件，并报告交接状态不确定。`printLayout.gap` 配置部件及边缘间距（默认 5 毫米），`printLayout.volume` 配置备用打印范围（默认 300 × 320 × 320 毫米）；明确设置的场景打印体积优先。

打印预览借用原始几何和材质，暂停悬停叠层而不丢弃已准备的索引，并将拖动绘制合并为每动画帧一次。关闭、替换源或销毁查看器时，先释放预览资源，再释放其源模型。悬停索引使用存储有界的紧凑面分块，同时保留精确三角形和材质接缝。所属模块的[性能测量](tests/viewer-hover.perf-results.json)涵盖 CPU 准备、拾取和叠层暂停，不测量 GPU 帧时间或端到端浏览器输入延迟。

查看器将排列操作放在浮动玻璃控件中。直接在打印板上选择并拖动部件。打印板选择器用于切换打印板，撤销始终可用。**在 Bambu Studio 中打开** 将当前打印板直接交给切片软件检查；布局问题会阻止交接。所选模型当前的验证状态可通过紧凑状态指示器查看。布局检查与自动模型验证相互独立，不会将未检查的模型视为已接受。

查看器以持续流动的青绿色表面光泽表示智能体正在处理模型，以沿模型上下移动的更亮扫描带表示模型验证。效果复用现有显示几何和一个共享动画时钟，每秒最多绘制 30 次，在隐藏或移出屏幕时暂停，启用减少动态效果时保持静止。处理期间禁用编辑、模型选择和打印操作；仍可旋转视角、缩放、精确指向以及返回模型。工作效果不会出现在项目封面中，也不会改变模型几何。验证结果使用现有的紧凑状态指示器，而不是持续显示文本横幅。

## 网格预览

模型预览通过 Three.js 的统一 USD 加载路径显示。导入的 STL 三角形转换为 USD；Blender 发布 `model.usda`，可编辑 `.blend` 原件单独保留。USD Physics 关节及 Isaac 机器人注解描述显示与验证所用的同一组网格。运动控件变换已加载装配，不重建几何。

`viewer/` 模块为任意对话提供通用 3D 视口；打印只是它的调用方之一，并非其唯一用途。一个目录对应一个 Cordis 插件，因此它随此插件发布，不单独成为一个包。

STL 场景文档将几何数据与放置方式分开：

- **数据块**表示一个网格：主机读取的几何数据、规范化的 STL 字节，以及
  旋转时所围绕的中心；
- **对象**通过缩放、旋转和位置放置一个数据块；缩放和
  旋转围绕网格中心进行，位置表示底部中心的所在位置，
  因此部件放大或转动后仍位于打印板上
- **场景**包含对象，以及用于检查它们的打印空间。

同一文件打开两次会放置两个共享同一数据块的对象，因此浏览器只获取一次几何数据，每次放置变更都无需改动它。

每次变更都是一条命令（`addObject`、`removeObject`、`setTransform`、`setVisible`、`setVolume`），命令返回一个新文档，因此撤销记录是一组先前的文档。智能体通过 `mesh_open`、`mesh_transform` 和 `mesh_remove` 发出命令，并通过 `meshState` 读取结果；将来的操纵控件也会使用相同命令。

`GET /api/print-studio/viewer/state?sessionId=…` 返回浏览器绘制的场景，包括每个对象的放置矩阵、状态和计数。`GET /api/print-studio/viewer/model?sessionId=…&datablockId=…` 返回一个数据块的字节；这些字节打开后不会变化，并按不可变内容缓存。

`bake.js` 将场景转换为文件数据：每个可见对象生成一个已应用变换的网格。它使用与测量相同的放置计算。导出和切片可以使用这些网格，无需修改源文件。

STL 导入接受最大 20 MiB、200,000 个三角形的文件。可编辑设计使用 [Three.js 模型接口](#editable-threejs-models)。场景和数据块为八个对话保留在内存中，在插件卸载时消失。从对话中打开的 STL 使用相同的标签页类型进行文件预览。

只有 `viewport/` 导入 Three.js。两种模型都使用 `transform.js` 处理放置；`bake.js` 为导出准备已放置的 STL 几何数据。

## 客户端构建

这是携带渲染器的 Cordis 配置项，因此浏览器端经过打包，而不是以普通 JavaScript 提供：Three.js 仅供此配置项使用，不进入共享的客户端模块表。`esbuild` 和 `three` 是 `apps/rumi` 的开发依赖；`build-client.mjs` 生成 `lib/client.js`，并在旁边放置 Three 的许可证。

```sh
pnpm --filter dsh-rumi run build:print-studio-client   # or `run build`, which includes it
```

## 账户登录

设置卡片在独立的 Rumi 桌面窗口中打开 Bambu 托管的登录页。桌面适配器只接受该窗口中位于 `https://bambulab.com` 的主框架发送的登录消息。社交登录打开系统浏览器，并通过临时回环监听器返回。关闭窗口、关闭 Rumi 或达到三分钟期限时，会移除监听器和消息处理器。

窗口在用户代理中提供以空格分隔的 `BBL-Slicer/v02.08.02.61` 标记，使 Bambu 页面启用 Studio 票据回调。页面通过 `get_localhost_url` 获得 `http://localhost:<port>` 地址后才打开系统浏览器；Bambu 拒绝数字形式的回环地址。浏览器登录必须保留该返回地址。收到票据后关闭登录窗口，并将焦点移回 Rumi。

Print Studio 验证返回消息，通过 Bambu 的票据端点交换票据，并通过 `ctx.credentials` 存储凭据。桌面适配器不保留令牌或密码。浏览器卡片需要 Rumi 的桌面桥接；独立的 DSH Web 无法打开此原生登录窗口。

托管页面和票据交换已使用真实 Bambu 账户验证；Bambu 更改页面后应重新验证。本地测试覆盖用户代理格式、回调地址、票据传递、窗口清理、消息验证和票据请求。

## Blender 编辑和 USD 预览

新建模型和网格编辑通过现有 shell 工具及其权限运行本地 Blender 后台 Python 脚本。打包后的 Rumi 在 `Resources/runtime/blender` 中包含 Blender；应用更新会将该运行时替换为固定版本。`blender_status` 默认使用内置运行时，安装损坏时报告错误，不会静默回退到独立安装。显式配置的 `blenderExecutable` 优先于自动发现。开发检出可使用 `blenderHome/tools/blender/Blender.app`、`/Applications/Blender.app` 或用户的 Applications 文件夹；`blenderHome` 默认为 `DSH_RUMI_HOME` 或 `~/.rumi`。随附的 [blender-modeling 技能](skills/blender-modeling/SKILL.md) 定义代理工作流程；状态工具返回已安装导出辅助脚本的路径。

辅助脚本在 `models/<name>/revisions/` 下保存不可变的 `.blend`、USD 和测量版本，再原子替换 `model.usda`。脚本启动完整 Blender 进程而不打开窗口。规范 USD 以米为单位、Z 轴向上；Three.js 转换为毫米、Z 轴向上的光标、测量及高亮坐标。Blender 编辑必须考虑对象变换并将查看器坐标除以 1,000。辅助脚本在原件中保留修改器，在查看导出文件中应用修改器。导出失败保留上一份预览；不完整版本文件保留供诊断。

连接件工具包提供 `outline_distances(points, outlines, batch_size=256)`，使用 Blender 内置的 NumPy 精确计算二维点到闭合轮廓的最短距离。输入和输出使用相同坐标单位，并支持零长度线段。成对计算的工作数组占用 O(batch_size²) 存储，输入和输出另占 O(points + segments)。选择边缘带时应使用它，而不是在 Python 中逐顶点遍历线段；平滑操作与发布检查均保持不变。在本包目录下运行 `blender --background --factory-startup --python-exit-code 1 --python tests/blender-outline-distances.py -- --benchmark`，可执行数值检查并获取三组合成数据计时。计时不包含启动与样例构造，也不设置 CI 实际耗时阈值。

撤销时，`helper['restore_revision'](model_directory, revision_directory_name)` 会验证并原子恢复现有版本的完整独立 USD 字节，不重建几何或删除历史。它要求存在对应的已保存 `.blend`，返回该原件路径，并保持当前 Blender 场景不变。后续编辑前应打开该原件。恢复操作将验证标记为待处理，绝不据此认定可打印；重新加载规范预览，并在声明接受前使用显式验证工具。回归测试为 `tests/blender-restore-revision.py`，使用上述同一 Blender 命令运行。

`viewer_load` 接受项目内的独立 ASCII USD 层，限制为 64 MiB 和 200,000 个可见三角形。在资产解析前拒绝引用、外部资源、组合、变体及动画。网格和内嵌材质值必须保存在一个静态层中。查看器优先发现 `models/<name>/model.usda`，再发现旧入口，并在两次相同轮询后重新加载。不可变快照 URL 保留光标及高亮的版本身份。无效导出保留上次成功预览并报告错误。USD 元数据和几何共享一次解析的表示。后台轮询检查文件标识、大小和纳秒时间戳后复用未变化的已验证字节；验证和接受操作强制重新读取字节。这些检查不证明可打印性。

`viewer_load` 选择模型并唤醒查看器并等待与显示的 URL、修订、变换和构建体积匹配的反馈。`load.status: ready` 确认可见渲染；`design.report` 包含测量结果，`design.parameters` 包含声明的默认值和已保存的值。构建和源文件失败返回对应错误；查看器隐藏、超时、替换、取消和卸载分别返回不同的未就绪结果。超时不代表模型不受支持。确认失败时选择仍然生效；不得据此推断已回滚或可打印。在 Print Studio 配置行设置 `viewerLoadTimeoutMs`（默认 8000 毫秒，范围 1–25000 毫秒）。

建模技能在编辑前提供[实体构建默认规则](skills/blender-modeling/SKILL.md#solid-construction-defaults)：封闭实体、Exact 布尔运算、独立机械部件、受控细节处理和选择性重网格化。这些是智能体指令，不是强制执行的操作限制；几何验证仍会检查结果。

`blender_status` 还会返回 `joints`，即 `blender/rumi_joints.py` 的路径：这是一个以毫米为单位的建模工具包，提供经过清理的 Exact 布尔运算，并从 `blender/joints/*.py` 加载连接件配方。每个配方为传入的两个零件添加配合特征并返回连接记录；工具包的 `publish` 把这些记录写成 USD 装配。[`printable-joints` 技能](skills/printable-joints/SKILL.md)列出每个配方及其样例在真实检查中得到的结果，其 `references/` 卡片给出调用方式和选项。配方是供智能体使用的起点，而不是经过验证的库：每个配方只在默认尺寸下单独检查过，依靠摩擦、磁力或五金件固定的连接保持未验证状态，若干被形状约束的连接读出的 `excessive_penetration` 略高于默认限值。在本包目录下运行 `Blender --background --factory-startup --python-exit-code 1 --python tests/blender-joints.py` 可执行工具包回归测试。

## 显式验证工具

智能体遵循[建模技能](skills/blender-modeling/SKILL.md#validate-a-finished-revision)。`blender_status` 依据插件的验证设置写入项目的 `.rumi/print-checks.json`。此后每次 `publish` 都在独立的 Blender 进程中检查新版本，并打印 `RUMI_CHECKS <json>`：计数非零的 Toolbox 与间隙结果、装配声明错误以及尺寸。没有该文件时，发布会打印 `status: unavailable`，失败或超时的检查绝不会报告通过。保留两个工具：`validation_mechanics` 接受模型 `path`，为当前版本运行缺失的装配、几何和适配阶段，任一阶段有阻断性错误时返回该阶段的结果，否则运行 Bullet；`validation_accept` 接受 `validation_mechanics` 返回的 `path` 和 `fingerprint`。指纹涵盖模型标识、源文件字节、放置变换、打印体积和验证策略；源文件或放置变化会使先前阶段的结果失效，未变化的已完成结果会复用。结果出现在工具返回值和 `meshState.validation` 中，未解决的结果仍在查看器中可见。打开或轮询预览只恢复验证历史，不启动 Blender 或 Bullet。源文件、放置变换和打印体积的变化会使接受状态失效；显式验证工具建立当前结果。过期检查会被取消并等待退出，已完成结果会复用。为兼容现有配置，仍接受 `validationRepairAttempts`，但它不产生作用。

装配检查验证声明并持久保存必需运动意图。几何检查运行 Blender Toolbox，不检查间隙或运行 Bullet。适配检查测量间隙和配置的打印体积，并准备物理部件。没有打印体积时，打印机适配仍未检查。Bullet 要求同一版本的装配、几何和适配结果均无阻断性错误，并使用已准备的部件。主机自行运行这些阶段，因此接受不依赖智能体的 `publish` 检查。接受要求所有先前阶段完成、机械覆盖完整且通过，并保留运动意图；它不执行仿真。工具失败、取消和源文件变化均不能确立接受。修复由智能体正常编辑后重新发布，不排入新轮次。

USD 检查使用不可变源快照，在转换为毫米前应用完整父级变换。旧模型需要渲染进程导出，由 `validationTimeoutMs` 限时；发布 USD 可避免依赖已打开的查看器。工具取消和关闭会终止并等待子进程，再释放快照和路由。检查期间查看器显示当前模型。`validationStateDirectory` 默认为 Rumi 主目录的 `validation`，原子保存已接受原件及必需运动意图；状态不可用或损坏会阻止接受。不改写现有项目文件。重启后仍可恢复已接受快照；显式检查重新确立当前接受状态。

固定版本的 GPL 许可 3D Print Toolbox 源码及许可证随包保存在 `blender/object_print3d_utils/`；`UPSTREAM.json` 标识源码修订。适配器检查流形、绕序、相交、退化、扭曲、厚度、锐边和悬垂。几何以毫米计，位置焊接容差为 0.001 mm。配置项为 `validation.minimumThicknessMm`（默认 1）、`degenerateThreshold`（0.000001，Toolbox 同时用于边长和面面积）、`overhangDegrees`（45）、`sharpDegrees`（160）及 `distortionDegrees`（45）。`validationTimeoutMs` 默认为 60000。这些是筛查阈值，并非经校准的打印公差。厚度采样和悬垂结果需要复核；有意重叠的实体也需要判断。对于包含两个或更多部件的装配，当两个不同部件之间的表面间隙小于 `validation.minimumClearanceMm`（默认 0.2，范围 0–2，0 表示禁用）时，两种制造模式下 `insufficient_clearance` 均为错误。间隙按放置后的毫米坐标测量，覆盖除由 `fixed` 连接直接相连的部件对之外的所有部件对；重叠报告为 0，`details.pairs` 按间隙从小到大列出最多八对及其 `gapMm`。该度量为顶点到表面的距离，可能漏掉纯边到边的最小值；通过不代表装配间隙可打印。已声明的运动接受下述额外检查。不会认证装配、支撑、材料强度或最终切片就绪性。查看器仅保留输入和预览限制，以及尺寸和包络测量。

在本包目录运行 `Blender --background --factory-startup --python-exit-code 1 --python tests/blender-validation.py` 和 `tests/blender-publish-checks.py`，可执行真实 Toolbox 与发布时检查回归。会话测试覆盖力学工具运行其前置阶段、版本缓存、过期结果、取消和失败。打包还通过组合后的 Host 配置及项目隔离策略，针对真实实体和可动轮子样例调用两个工具，覆盖 Blender、Bullet、接受、缓存结果、跨项目拒绝、过期版本拒绝及单个已记录的工具调用轮次。参见[已安装验证工具验收](../../tests/README.zh.md#validation-tool-qualification)。

## 机械验证

模型使用 USD Physics 刚体、碰撞 API 以及固定、旋转或滑动关节。默认 prim 应用 `IsaacRobotAPI`；有序的 `isaac:physics:robotLinks` 和 `isaac:physics:robotJoints` 关系列出每个网格与关节。链接应用 `IsaacLinkAPI`，关节应用 `IsaacJointAPI`，首个链接是固定测试根部件。标准刚体关系、局部坐标系与限位定义预期运动；每个链接必须连接到根部件。旋转限位用度，滑动限位用米。关节两侧坐标系必须在保存的静止姿态相交，运动轴必须一致。有限范围定义覆盖要求，不代表存在物理限位。`rumi:control`、`rumi:manufacturingMode`、`rumi:sequences` 和 `rumi:disassembly` 保存 Rumi 特有的控件及制造要求。运动意图跨版本和重启保留；删除必需控件或缩小范围不能掩盖失败检查。参见[物理运动声明](skills/blender-modeling/SKILL.md#declare-physical-movement)。

Blender 未发现阻断性几何错误后，主机通过协议 2 将求值后的物理网格及装配描述传给内置 Bullet 程序。双精度 GImpact 接触保留凹几何。仅固定声明的根部件；包括保持件在内的所有其他部件均保持动态。固定、旋转和滑动连接仅描述预期相对行为，不创建理想关节。通用探测挑战禁止运动，并通过力驱动允许运动到采样姿态，同时监测每个连接及碰撞对。保持检查测试的是脱离而非紧度：部件可在其间隙内移动，只要连接几何将其限制在 `mechanics.retentionTravelMm`（默认 2，范围 0.1–10）的枢轴位移和 `mechanics.retentionTiltDegrees`（默认 15，范围 1–45）的倾斜之内即通过。部件位移或倾斜超出任一界限，或保持探测结束时仍在向外移动，则报告 `unstable_at_rest` 和 `unretained_part`。`linearToleranceMm` 和 `angularToleranceDegrees` 仅决定被驱动关节是否到达目标（`movement_blocked`）以及 `movement_below_tolerance`。报告记录部件、连接和序列覆盖，以及解析后的仿真策略。错误返回调用工具；不支持的物理行为及不完整覆盖保持未验证状态。程序缺失、超时或报告格式错误均不能通过。`mechanics.maxTotalSteps` 默认为 2,000,000（可配置为 1,000 至 10,000,000），超出后装配保持未验证；即使跳过完整运动，初始连接检查仍会报告缺陷。

装配最多包含 128 个物理部件和 128 个连接。将不连通实体合并为一个网格不能提供物理连接。`publish(directory, configure_robot=callback)` 向回调提供 OpenUSD stage 以编写标准声明，并在可编辑 `.blend` 中保留其 USD 层；省略回调保留已有声明。Blender 内置 OpenUSD 按照 NVIDIA 的[无 Kit 方案](https://nvidia.github.io/simready-foundation/2026.07.1/features/FET_101_ISAAC.html)直接编写 Isaac 注解，无需 Isaac Sim。注解描述预期行为，Bullet 探测网格是否实现该行为。不支持的图耦合、变形连接及数值不确定性需要复核。未声明 `rumi:disassembly` 步骤的 `separate` 装配仅由探测验证；仅当声明这些步骤（仅平移的逆向装配路径）时才检查移除路径。

`bulletExecutable` 指定开发环境的显式路径；打包后的 Rumi 使用内置程序，不搜索 `PATH`。`mechanicsTimeoutMs` 默认为 600000（十分钟），独立限制实际运行时间。`mechanics.retentionWorkers` 默认为 4（可配置为 1–4）：初始检查通过后，独立保持载荷以有界批次并行运行，各工作线程使用独立碰撞形状。运动步骤仍按顺序执行；结果保持串行顺序，且始终监测每个连接。每个连接的独立保持载荷在保存姿态和每个范围端点姿态运行；中间运动采样和返回运动仅探测被移动的连接。对于序列，最后一个路点探测每个连接，中间路点仅探测被驱动的连接。不会根据表面对称性或距离省略探测。原生报告上限为 8 MiB。智能体上下文和工具结果汇总通过的探测数量，并保留所有失败或不确定的探测、覆盖范围及策略；查看器状态保留完整诊断报告。`mechanics` 策略配置密度、力及扭矩上限、持续时间、积分、接触容差、重力、摩擦和采样。默认重力为 `[0,0,-9.81]` m/s²，摩擦系数为 `0.2`，运动采样间隔为 30 度或 2 mm，`probeDurationSeconds` 为 0.25，`maxPenetrationMm` 为 0.15，拆卸路径采样间隔为 0.2 mm。这些是筛查假设，并非经过校准的打印机或材料参数。通过仅涵盖报告中的有限探测，不能保证连续无碰撞、所有同时运动组合、支撑移除、强度、磨损、变形或切片就绪。`printReady` 保持为 false。

## 持久活动部件控件

打开模型时，查看器会显示可见的关节手柄。旋转视角时，手柄会随关节被模型遮挡而隐藏，并在关节重新可见时显示。选择手柄即可打开对应控件；手柄重叠、被遮挡或位于视野外时，可使用**选择关节**。平移、旋转视角或缩放时，选中的控件会保持打开，并在对应手柄不可见时移到左下角。点击左下角的**活动部件**或按 Escape 键可隐藏控件。运动只改变本地预览姿态。临时编辑期间，活动部件按钮被禁用。运动期间及重置后，光标高亮跟随可见部件。请求绑定源码的光标编辑前请重置姿态；预览运动不代表机械验证通过。

USD 旋转和移动关节默认生成滑块。根节点可选的 `rumi:motionControls` JSON 可选择滑块、双轴面板或标量曲线，并绑定绝对关节路径；未声明的运动保留自动滑块。关节限位和保存姿态提供范围与重置值。编写方式见[运动控件](skills/blender-modeling/SKILL.md#movement-controls)。自动标签使用 `rumi:control` 或子网格名称。预览将关节坐标系应用于部件及其后代，包括固定附件。共享控件使用重叠的声明范围，并要求单位一致。最多支持 12 个独立运动；格式错误的声明、闭环或不支持的绑定会保留几何体并报告 `assembly_motion_unavailable`，不显示误导性控件。装配描述相同时，姿态值可在重新加载后保留。预览变换借用原始网格资源，不修改导出几何体，也不代表机械验证通过。

## 可编辑的 Three.js 模型

将每个独立预览保存在 `models/<name>/model.usda`，并保留可编辑 Blender 原件。查看器通过 Three.js 渲染 USD，不执行项目代码。迁移 GLB 模型时，打开其 `.blend` 或使用辅助脚本 `import_mesh` 导入 GLB，再调用 `publish`。旧装配声明一次性转换为 USD Physics 关节，此后保留原生 USD 描述。保留原文件。旧 JavaScript 入口必须通过受限建模工具导出真实几何。不会自动迁移任何项目。

`viewer_transform` 在不修改源码的情况下应用统一缩放、以度为单位的 XYZ 旋转，以及以毫米为单位的底部中心位置。`viewer_camera` 根据方位角和仰角调整观看方向，不改变几何数据。两者均作用于整个已加载设计；命名部件通过源码编辑。成功重建后保留相机状态和放置方式。导入或构建失败时保留上次成功的模型，并显示错误；`meshState` 包含源码版本、构建错误和渲染进程报告的测量结果。测量需要预览处于挂载状态，且不能证明模型已可打印。现有的 STL 导入和场景工具仍可单独使用。

每个对话拥有独立的实时预览。打开项目会立即请求状态；在项目列表或文档隐藏时暂停定期轮询，恢复可见时立即刷新。最后选择的入口和打印平台尺寸以原子方式保存在项目的 `.rumi-viewer.json` 中，重启后打开预览时恢复；没有保存的选择时打开第一个发现的模型。切换模型会在主机接受选择后立即刷新预览，无需等待定期轮询，并重置相机和位置。保存的入口缺失或不可读时显示错误，不会替换为其他模型；选择可用模型即可恢复。自动发现排除符号链接目录和入口。仅加载选中的源文件，其他模型文件保留在磁盘上。STL 场景对象仍仅保存在内存中。

源码加载和快照是由 Print Studio 插件拥有的 Cordis effects。快照 effect 收集路由注册返回的原始 disposer。卸载会停止源码轮询，等待已接纳的加载和轮询结束，并释放路由；查看器丢弃延迟完成的导入，并释放 GPU 资源。轨道控件在画布离开文档之前断开监听。场景淘汰会释放对应的验证状态；正在检查的场景会保留到检查完成。测试使用真实 Cordis 上下文验证这些路径。

### 视觉澄清

通过 `viewer_load` 加载可编辑模型后，用 `viewer_highlight` 绘制临时表面网格。传入当前模型的 revision、url、简短的 label，以及项目相对路径 meshPath。模型路径可使用当前模型的 path 或项目相对路径 `selectedModel`。将 ASCII 或二进制 STL 写在模型目录外，使用模型局部毫米坐标、Z 朝上，应用部件变换。网格可包含多个不相连的表面。在移动预览中，位于原始表面的覆盖三角形会随对应的部件移动。

查看器直接绘制青绿色三角面，深度测试保留模型遮挡。高亮不影响原始几何、测量、导出或封面。传入空字符串 meshPath 可清除高亮。更换源码版本或模型也会清除高亮。只有 rendered 表示可见查看器已绘制该网格。蓝色光标高亮仍按所选范围显示。

Rumi 可以用用户的语言为这些三角面覆盖的特征提供简短的 `regionName`。将指针悬停在已命名的表面上即可看到名称。点击或轻触该表面可固定标签，旋转视角时标签会继续显示。使用键盘聚焦预览也可显示标签。激活标签可将区域添加到聊天输入框上方。点击聊天中的区域标签可重新打开预览；点击关闭按钮可移除引用。标签在当前高亮有效期间保留，每条接收的请求都会在 `modelFocus.requests` 中记录关联特征及源码版本。更换高亮或模型版本会清除标签。

整个模型的悬停标签由 USD 文件旁的 `model.regions.json` 提供。命中表面时显示首个匹配的特征名称，未匹配时显示剩余区域的名称。即使当前没有高亮，预览也可在本地查找名称。区域表使用 SHA-256 与 USD 版本关联。模型更改后需要匹配的区域表，区域表格式错误时仍可查看模型。添加到聊天的区域包含特征 ID 和源码版本。参见[为整个模型命名](skills/name-model-regions/SKILL.md)。

光标模式位于左下角的紧凑玻璃胶囊中。使用鼠标或触控板时，仅显示当前模式；悬停或键盘聚焦后显示全部四个选项，选择期间焦点会保持展开。触屏控件始终展开，点击区域为 44px。减少透明度或提高对比度时使用不透明背景。

`viewer_cursor_snapshot` 从调用方对话中打开的查看器请求一次新的捕获。按 Session 隔离的长轮询会唤醒查看器。查看器处理请求时会捕获固定区域，或重新采样当前悬停位置。只要预览仍打开，即使窗口隐藏也可以捕获固定区域。成功结果包含 PNG 附件、捕获时间、指向的对象或部件路径、三角形索引、世界坐标中的位置和高斯半径、相机，以及几何和放置标识。命中可编辑模型时，使用 `region.modelLocalPoint`、命中部件及范围在 `identity.design` 中定位标记表面。移动预览期间，模型局部坐标保持在 `viewer_highlight` 使用的已保存坐标系，世界坐标随摆动的部件改变。

只有请求的捕获会传输到主机。工具的结构化结果和持久图像附件进入常规对话日志，使 agent 的视觉输入可回放。没有交点时返回 `no_hit`。无法捕获时返回 `viewer_unavailable` 及原因，例如预览已关闭、窗口隐藏且没有固定区域、正在临时编辑、预览姿势已移动或处于打印布局。请求八秒内未收到响应时，原因是 `response_timeout`。源码或放置标识变化时返回 `stale_view`，捕获或图像存储失败时返回 `capture_failed`，并发请求返回 `busy`。取消、场景淘汰和插件卸载都会释放待处理请求。响应按 Session 和请求隔离，并在进入工具输出前验证。图像最长边限制为 960 像素，编码字符数不超过三百万；附件服务验证并存储 PNG 字节。agent 高亮仍由 `viewer_highlight` 独立控制，不随指针移动。

没有固定确认短语解析器或基于高亮的编辑门禁。明确请求和已提供的选项按上下文处理；意图不明确时需要澄清。Live Voice 在上次委派后的第一个转录片段到达时请求捕获，并将带时间戳的结果和图像保存为与用户语音消息 ID 关联的独立后台上下文。用户语音气泡只显示其话语。这近似于说话时的指向，不是音频起点采样。agent 必须使用附带引用，不能用后来的指针位置替代。查看器唤醒也会立即传递高亮更新，无需等待两秒场景轮询。

`viewer_highlight` 最多等待八秒，直到可见渲染器确认匹配的高亮 ID 和源码标识。只有 `rendered` 表示已渲染；`not_rendered`、取消或被替换都不能描述为高亮已显示。渲染不等于用户确认，此工具不捕获截图。

### 高亮诊断

`viewerDiagnosticsDirectory` 默认为 `~/.rumi/viewer-logs`。私有 JSONL 文件记录高亮请求 ID、主机唤醒与状态传递、客户端应用与反馈阶段、文档可见性、视口尺寸、标识比较以及完成耗时。客户端耗时使用单调时钟；主机接收时间用于确定跨进程顺序。不记录模型源码、图像、音频、转录文本或凭据。文件保留到手动删除。日志 I/O 错误会使所属操作失败；客户端诊断传递失败也会报告到浏览器控制台。

`not_rendered` 包含 `reason`：`ack_timeout` 表示没有收到匹配确认，并不能证明高亮未显示；`viewer_hidden` 和 `render_failed` 是渲染器明确报告的状态。隐藏文档恢复可见时会重绘并报告当前高亮。仅高亮更新会复用几何、材质和测量报告，只更改区域 uniform。放置、构建体积和源码变化会使测量失效。CPU 诊断命令 `node --import tsx/esm apps/rumi/brand/print-studio/tests/viewer-highlight.perf.ts` 可通过 `--rebuild` 比较 uniform 更新与重建；它不包含网络、模型响应或 GPU 耗时。

### 光标驱动的网格高亮

在 3D 预览中点击模型表面，即可固定浅蓝色高亮。再次点击预览画布中的任意位置，即可解除固定并恢复悬停高亮。旋转视角、缩放或将指针移出预览时，该位置仍保持固定。切换到局部、表面、整个部件或边缘时，高亮范围围绕同一个点调整。模型或放置位置变化时会解除固定。

光标将高斯局部选区限制在所指网格及其连通表面内。表面在开放边缘、材质接缝和至少 35 度的折角处终止；这些是几何区域，不是语义解剖部位。本地控件可选择局部、完整表面、整个网格部件或附近的边界边缘。控件与模型选择器共用圆角玻璃质感，选中项显示为内嵌分段，并提供清晰的键盘焦点。查看器为每个显示副本一次性构建几何局部面分块包围盒和表面属性；指针移动每帧最多更新一次 uniform，无需模型调用、主机请求、几何上传或洪水填充。索引在模型加载时准备，不计入稳定状态的拾取延迟。

快照中的 `region.selection` 记录捕获时的光标选区范围。建模 agent 根据原始捕获内容理解语音请求，并选择青绿色覆盖层所需的三角面。

## 连续网格编辑

agent 使用 `viewer_controls` 声明带标签的滑块、双轴面板和标量曲线。每个轴绑定一个数值，并指定范围、步长和重置值。面板可以仅展示所提供模型参数中的一部分。曲线控件的手柄位于水平中央，随数值上下移动。渲染器独立于模型操作；标签描述真实绑定。控件悬浮在查看器右上角，必要时可滚动，并支持键盘输入、独立重置、焦点指示和降低透明度。[control-widgets skill](skills/control-widgets/SKILL.md) 介绍通用控件。[网格编辑控件](skills/mesh-edit-controls/SKILL.md) 根据请求选择有用的调整、编写变形，并处理预览、修改和保存。其活动工作流提示词也适用于已有项目。

可执行的 JavaScript 参数预览被禁用。几何适配器保留其几何行为：鼓包、弯曲、扭转和渐缩更新 GPU uniforms，无需重建。声明的轴使用 0..1 归一化值，中性值为 .5。区域与保存规则见 [built-in-mesh-operations](skills/built-in-mesh-operations/SKILL.md)。将指针悬停在编辑中的网格上可显示蓝色高亮，点击可固定高亮，切割时保留的网格表面也可选取。调整编辑控件会解除固定。编辑期间查看器暂停光标快照和缩略图。几何检查描述已保存的原件。

松开控件会更新会话所属的值。用户满意或开始新任务时，先完成最新可见编辑；明确取消则放弃。Freeze 捕获最新可见值、锁定控件，并在 `artifacts/shape-controls/` 写入绑定源文件的配方。代理使用 `apply_shape_controls` 将配方应用于匹配的 Blender 源文件，发布新版本并加载。Close 恢复已保存预览。源文件变化使控件失效；过期反馈被拒绝。隐藏的查看器报告 `viewer_hidden`，恢复可见时渲染相同控件。渲染异常报告 `render_failed`，并在控件状态和工具结果中包含原因。预览和保存都不能认证打印就绪性。

网格编辑控件采用 `prepare → validate → review → present` 流程。`open` 是准备操作的别名，不会显示控件。准备时会保存绑定，并要求为每个轴说明预期效果和需保留的特征。

验证使用已保存的 USD 和查看器的变形实现，以固定正面、侧面和后视角渲染端点及组合极值。图像包含编辑前、编辑后和统一位移色标的叠加图（低于 0.01 毫米为灰色，从金色渐变至 20 毫米的红色）；切割改为标记移除区域。测量来自实际表面顶点，而非晶格峰值。比较任务通过浏览器任务调度器而非定时器让出执行权，避免隐藏窗口的定时器节流逐项延迟验证。辅助控件在非零变形量下测试。agent 必须评估每个轴及组合效果后才能展示控件；渲染完成不等于通过质量评审。

待验证或待评审状态会跨轮次和上下文压缩持续出现在必需上下文中。验证超时会保留已准备的 ID 供重试。重新加载相同字节会保留源对象、控件和评审证据，同时请求新的渲染器反馈；过期确认无法完成此次加载。没有剩余控件时，上下文会明确说明未准备或展示任何临时控件。重新准备或源模型变化会使证据失效；源对象释放或应用重启会丢弃待处理草稿。准备期间保留现有可见控件。失败、取消、不完整或过期的验证不能授权展示。

`surface` 操作使用模型坐标中的选区边界，因此三角形顶点展开不会改变其坐标系。轮廓控制沿连续的侧视外形移动，包括顶部的垂直位移，并在侧面平滑衰减、固定底部接缝。控制站可固定，或共享位移控件与方向以保持局部刚性。环带和凹槽使用径向位移；凹槽宽度按弧长计算。平面操作将高度带核心区域投影到声明的平面，并在边缘过渡。有一致朝向的空心壳可声明壁厚，使外壁和内壁分别投影到不同平面；无法判断朝向的边缘在预览前报错。曲面验证拒绝塌陷或翻转的三角形。图像审阅前，主机使用内置 Blender 检查实际预览三角形，阻止各端点和组合极值产生新的相交对，包括与未编辑部件的相交。已有相交对仍会报告；附近的源模型缺陷不能成为接受新相交对的理由。壁厚和配合仍需测量；相同位移不保证它们保持不变。预览与 Blender 使用相同公式，冻结配方通过源文件哈希绑定到已审阅模型。

`tests/surface.spec.ts` 覆盖顶部连续性、旋转坐标系、平面区域、壳体偏移、拒绝路径和 Python 一致性。头盔验收用例先运行 `node tests/surface-acceptance.mjs input.json output-directory`，输入 JSON 中提供绝对路径 `source` USD 及匹配的 `blend`，然后使用内置 Blender 运行 `--background --python-exit-code 1 --python tests/blender-surface-acceptance.py -- output-directory blender/rumi_blender.py`。测试不修改项目，输出渲染对比、顶点一致性、固定接口、三角形朝向和壁厚采样结果，并拒绝生产几何验证器错误数量增加的结果。它验证指定配方，不验证新代理能否自行推导配方。

`viewer_controls` 替代 `viewer_shape_controls`；调用者打开控件时必须显式提供控件声明。已存储的旧配方保留几何格式。任意 Blender 参数需要先建立忠实的实时绑定；重命名变形滑块不会创建该绑定。

连续平面切割在相同的悬浮玻璃表面上提供高度、倾斜和侧倾控件。打开切割控件会清除先前的高斯高亮；连续的青色引导线跟随实际切边，替代散布的光斑。冻结或关闭时引导线消失，切割完成前拒绝新的区域高亮。预览以一个模型局部平面裁剪选中的部件，使用模板缓冲区绘制横截面，无需重建几何；空腔开口保持可见。保存的配方使用 Blender 精确布尔交集修剪并封闭相同的保留半空间。高度沿 direction 在 ±limit 范围内移动；倾斜和侧倾相对中性平面各跨越 ±60°。请求编辑切割时会先打开这些控件，再应用结果。要恢复已移除的材料，请从较早的修订开始。曲线切割、挤出和倒角仍需普通 Blender 编辑。在本包目录中运行 `blender --background --python-exit-code 1 --python tests/blender-cut.py -- blender/rumi_blender.py` 可执行 Blender 回归测试。

## 实时模型上下文

Print Studio 根据选择、模型源、测量、高亮和形状控件的变化维护查看器状态。必需的 `rumi:mesh-state` 上下文提供器在每次模型请求（包括重试）前同步读取状态，不扫描文件或操作查看器。快照包含完整场景报告和工作模型。查看器尚未初始化时，返回 `viewer_not_initialized`，而不是声称场景为空。模型发现和源文件轮询仍由查看器负责；状态变化本身不会唤醒智能体。

Rumi 在 `agent/request` 中通过持久化的表面替换移除先前的运行时上下文快照；空的开发者消息替换不会产生模型可见消息，普通智能体循环随后接纳新快照。原始快照保留在会话日志中，用户消息、操作结果和请求时引用保持完整。未变化的快照也会刷新，这可能降低提供器的前缀缓存复用，但无需修改共享框架代码即可保证路由准备和重试期间只有一个当前快照。不注册 `mesh_state` 工具。工具执行时仍验证版本身份，因为模型生成期间查看器状态可能变化。

## 模型选择与智能体工作

选中的模型表示用户的浏览状态。模型选择按钮上的绿色小圆点独立标识智能体声明的工作目标，无障碍名称会说明圆点的含义。`viewer_working_model` 工具验证已发现的模型入口，设置或清除工作目标，但不切换预览。并发智能体可以标识不同模型。进入空闲状态、取消后进入空闲状态、智能体释放和插件释放都会清除对应标识。当所选模型与声明的工作目标冲突时，模型放置、高亮和形状操作会拒绝执行。声明表示工作意图，并不验证 shell 命令实际编辑了哪些文件。

必需的 `rumi:model-focus` 运行时上下文使用 `ctx.systemPrompt.context`，由智能体循环记录。它包含当前选择、可用模型、智能体的工作目标，以及人工请求进入收件箱时捕获的、关联消息 ID 的模型选择。即使用户随后浏览其他模型，排队请求也保留各自的引用。重启后无法恢复的引用保持未知，不以当前选择代替。语音还会在初始转写捕获时记录选择，并与指向引用一起提供。名称和指向引用优先，选择提供默认值；仅浏览不会改变正在进行的工作目标，意图冲突时需要澄清。提出澄清前清除工作声明。新模型在入口存在且智能体声明工作目标后获得标识。

打开项目会恢复验证历史，不运行检查。发布会打印低成本检查结果；智能体通过验证工具启动 Bullet 和接受。验证结果不会隐藏模型。

### Bambu 应用安装

在 macOS 上，选择 **Set up Bambu Studio**，即可从 `bambulab/BambuStudio` 的 GitHub 发布安装 Bambu Studio 02.09.01.70。安装器使用固定的 SHA-256 校验和验证通用磁盘映像。暂存的应用必须通过 Bambu 团队 `T3UBR9Y3B2` 的深度代码签名验证和 macOS Gatekeeper 评估。Rumi 将应用安装到 `$DSH_HOME/print-studio/applications`，也识别 `/Applications` 和 `~/Applications` 中的副本。

安装过程报告下载、验证、安装及失败状态。并发请求共用一次安装。安装失败时保留现有副本，重试时重新下载。插件关闭时等待安装和暂存清理完成。磁盘映像卸载失败时保留暂存目录，并报告清理失败。`appDownloadTimeoutSeconds`（900）和 `appDownloadRetries`（2）配置每次下载的网络时限和重试次数。挂载、复制、签名和 Gatekeeper 步骤分别限时 600 秒。更新固定版本时，要更新校验和，并在每个目标平台验证发布者签名和应用启动。

模型专用控件使用 `operation: fields` 和纯数据位移网格。预览在选定 USD 网格的副本上插值并混合位移，取消后恢复原始几何体。冻结配方在 Blender 中使用相同的插值方法。预览器不会执行项目代码。这些编辑保持网格连接关系，但不保证壁厚或无自相交。参见[位移场编写](skills/mesh-edit-controls/references/fields.md)。 每个控制轴都需要在 `values` 中提供条目，位移场的初始值为零。验证分别报告缺少或格式错误的 `values`、缺少或重复的绑定、无效数值以及超过 32 个参数，并说明修正方法。

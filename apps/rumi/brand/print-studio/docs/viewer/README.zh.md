# 网格预览与选择

[English](README.md) | 中文

Three.js 查看器加载已发布的 USD 模型，并将导入的 STL 几何转换为 USD 以供显示。每个对话拥有独立的预览。请从仓库根目录运行高亮性能诊断命令。

## 可编辑的 Three.js 模型

`viewer_transform` 在不修改源码的情况下应用统一缩放、以度为单位的 XYZ 旋转，以及以毫米为单位的底部中心位置。`viewer_camera` 根据方位角和仰角调整观看方向，并返回模型标识和相机角度。两者均作用于整个已加载设计；命名部件通过源码编辑。成功重建后保留相机状态和放置方式。导入或构建失败时保留上次成功的模型，并显示错误；`meshState` 包含源码版本、构建错误和渲染进程报告的测量结果。测量需要预览处于挂载状态，且不能证明模型已可打印。现有的 STL 导入和场景工具仍可单独使用。

每个对话拥有独立的实时预览。打开项目会立即请求状态；在项目列表或文档隐藏时暂停定期轮询，恢复可见时立即刷新。最后选择的入口和打印平台尺寸以原子方式保存在项目的 `.rumi-viewer.json` 中，重启后打开预览时恢复；没有保存的选择时打开第一个发现的模型。

切换模型会在主机接受选择后立即刷新预览，无需等待定期轮询，并重置相机和位置。保存的入口缺失或不可读时显示错误，不会替换为其他模型；选择可用模型即可恢复。自动发现排除符号链接目录和入口。仅加载选中的源文件，其他模型文件保留在磁盘上。STL 场景对象仍仅保存在内存中。

源码加载和快照是由 Print Studio 插件拥有的 Cordis effects。快照 effect 收集路由注册返回的原始 disposer。卸载会停止源码轮询，等待已接纳的加载和轮询结束，并释放路由；查看器丢弃延迟完成的导入，并释放 GPU 资源。轨道控件在画布离开文档之前断开监听。场景淘汰会释放对应的验证状态；正在检查的场景会保留到检查完成。测试使用真实 Cordis 上下文验证这些路径。

## STL 场景对象

每个场景对象指定一个共享网格数据块的放置方式。缩放和旋转以网格中心为基准，位置决定网格底部中心在打印板上的坐标。同一文件打开两次会产生同一网格的两个放置实例。每条命令返回新的场景文档，早先的文档构成撤销历史。烘焙和测量使用相同的放置变换。导入文件上限为 20 MiB、200,000 个三角形。最多八个对话的场景保留在内存中，直至场景被逐出或插件卸载。

`GET /api/print-studio/viewer/state?sessionId=…` 返回浏览器绘制的场景，包括每个对象的放置矩阵、状态和计数。`GET /api/print-studio/viewer/model?sessionId=…&datablockId=…` 返回一个数据块的字节；这些字节打开后不会变化，并按不可变内容缓存。

## 实时模型上下文

Print Studio 根据选择、模型源、测量、高亮和形状控件的变化维护查看器状态。必需的 `rumi:mesh-state` 上下文提供器在每次模型请求（包括重试）前同步读取状态，不扫描文件或操作查看器。快照包含完整场景报告和工作模型。查看器尚未初始化时，返回 `viewer_not_initialized`，而不是声称场景为空。模型发现和源文件轮询仍由查看器负责；状态变化本身不会唤醒智能体。

Rumi 在 `agent/request` 中通过持久化的表面替换移除先前的运行时上下文快照；空的开发者消息替换不会产生模型可见消息，普通智能体循环随后接纳新快照。原始快照保留在会话日志中，用户消息、操作结果和请求时引用保持完整。未变化的快照也会刷新，这可能降低提供器的前缀缓存复用，但无需修改共享框架代码即可保证路由准备和重试期间只有一个当前快照。不注册 `mesh_state` 工具。工具执行时仍验证版本身份，因为模型生成期间查看器状态可能变化。

## 模型选择与智能体工作

选中的模型表示用户的浏览状态。模型选择按钮上的绿色小圆点独立标识智能体声明的工作目标，无障碍名称会说明圆点的含义。`viewer_working_model` 工具验证已发现的模型入口，设置或清除工作目标，但不切换预览。并发智能体可以标识不同模型。进入空闲状态、取消后进入空闲状态、智能体释放和插件释放都会清除对应标识。当所选模型与声明的工作目标冲突时，模型放置、高亮和形状操作会拒绝执行。声明表示工作意图，并不验证 shell 命令实际编辑了哪些文件。

必需的 `rumi:model-focus` 运行时上下文使用 `ctx.systemPrompt.context`，由智能体循环记录。它包含当前选择、可用模型、智能体的工作目标，以及人工请求进入收件箱时捕获的、关联消息 ID 的模型选择。即使用户随后浏览其他模型，排队请求也保留各自的引用。重启后无法恢复的引用保持未知，不以当前选择代替。语音还会在初始转写捕获时记录选择，并与指向引用一起提供。名称和指向引用优先，选择提供默认值；仅浏览不会改变正在进行的工作目标，意图冲突时需要澄清。提出澄清前清除工作声明。新模型在入口存在且智能体声明工作目标后获得标识。

## 指向与区域命名

通过 `viewer_load` 加载可编辑模型后，用 `viewer_highlight` 绘制临时表面网格。传入当前模型的 revision、url、简短的 label，以及项目相对路径 meshPath。模型路径可使用当前模型的 path 或项目相对路径 `selectedModel`。将 ASCII 或二进制 STL 写在模型目录外，使用模型局部毫米坐标、Z 朝上，应用部件变换。网格可包含多个不相连的表面。在移动预览中，位于原始表面的覆盖三角形会随对应的部件移动。

Rumi 在创建或更新特征名称时读取模型源文件、查看从不同角度渲染的图像，并分析已保存的网格。`viewer_analyze_surfaces` 列出各部件以及“表面”光标可选中的连通表面。实体特征可以覆盖一个表面中的部分三角形、多个表面或整个部件。轮廓、点和铰链活动间隙等空间也可以有各自的名称。简短的定义可以解释新术语，别名则让用户用熟悉的词指代同一特征。Rumi 将名称和位置存入 USD 文件旁的 `model.regions.json`。参见[为模型特征命名](../../skills/name-model-regions/SKILL.md)。

每个区域表通过 SHA-256 关联一个 USD 版本，最多可保存 256 个命名特征。模型更改后需要匹配的区域表。已有的方框区域表仍可显示。如果区域表包含旧式方框，或只用体积而未指定任何网格表面，`needs_surface_regions` 会提示重新检查实体特征。表面选择器无法解析时，`viewer_load` 和 `meshState` 会报告区域表无效，`regionError` 会列出受影响的特征。其他已解析的特征仍可使用。修正区域表后，同一模型上的选区会随之更新。

调用 `viewer_analyze_surfaces` 时传入 `coverage: true`，可检查已保存的区域表中尚未命名的三角形。有效的区域表也可能存在覆盖缺口。概览返回全部与未覆盖三角形的数量和面积（平方毫米），并分页列出受影响的部件。指定 `partPath` 后，工具用 `surfaceIds`、`faceRanges` 或 `faceRangesPath` 所指的 JSON 数组给出未覆盖区域的精确选区。翻页时传入返回的 `sourceHash` 和 `regionMapKey`，确保继续查看相同版本的两个文件。

模型有已保存的名称时，光标默认使用**命名区域**，否则使用**局部**。将指针悬停在特征上即可高亮该特征并显示其名称。放大可逐级显示已命名的细节，即使某个细节表面和包含它的特征同宽也能分别选中。较小的表面通过 `parentId` 指明包含它的命名表面。点击或轻触可固定当前选区，旋转或缩放时仍会保留。激活标签可将特征添加到聊天输入框上方。点击聊天中的区域标签可重新打开预览，点击关闭按钮可移除引用。每条接收的请求都会在 `modelFocus.requests` 中记录关联特征及源码版本。源码或区域定义更改时会清除引用。

要以青绿色显示已保存的特征，请将名称、ID 或别名传给 `viewer_highlight.region`，并提供当前模型标识。查看器绘制的位置与命名区域模式相同。自定义 STL 高亮可通过 `regionName` 提供标签。高亮不影响测量、导出或封面。传入空字符串 `meshPath`、更换源码版本或切换模型会清除高亮。只有 `rendered` 表示可见查看器已绘制高亮。

`viewer_cursor_snapshot` 捕获调用方对话预览中的固定选区或当前悬停目标。只要预览仍打开，即使窗口隐藏也可以捕获固定选区。结果包括 PNG、捕获时间、相机和模型标识。光标命中网格时，结果包括部件路径、三角形索引和命中点。对于已保存的特征，`namedRegion` 标识其位置和区域表版本，即使光标命中空白处的特征也一样。活动部件预览期间，`region.modelLocalPoint` 定位已保存的表面，世界坐标则随部件姿势改变。

捕获包含可编辑模型中的选中三角形时，`mesh.path` 提供 `.rumi/cursor-selections` 下二进制 STL 文件的项目相对路径，`mesh.triangleCount` 报告导出的三角形数量。STL 使用模型局部毫米坐标，Z 轴朝上，应用已保存姿势下的部件变换，不含查看器的放置变换。要以青绿色显示用户选区，请先核对 `identity.design` 与当前模型，再将导出的路径原样传给 `viewer_highlight.meshPath`。无法导出时，`meshUnavailable` 报告 `unsupported_model`、`empty_selection`、`geometry_unavailable` 或 `storage_failed`。仍可查看图像和光标详情。

只有请求的捕获会传输到主机。工具的结构化结果和持久图像附件进入常规对话日志，使 agent 的视觉输入可回放。

没有交点时返回 `no_hit`。无法捕获时返回 `viewer_unavailable` 及原因，例如预览已关闭、窗口隐藏且没有固定区域、正在临时编辑、预览姿势已移动或处于打印布局。请求八秒内未收到响应时，原因是 `response_timeout`。源码或放置标识变化时返回 `stale_view`，捕获或图像存储失败时返回 `capture_failed`，并发请求返回 `busy`。取消、场景淘汰和插件卸载都会释放待处理请求。

响应按 Session 和请求隔离，并在进入工具输出前验证。图像最长边限制为 960 像素，编码字符数不超过三百万；附件服务验证并存储 PNG 字节。agent 高亮仍由 `viewer_highlight` 独立控制，不随指针移动。

## 光标选区

点击 3D 预览即可固定选区。再次点击预览画布中的任意位置，即可解除固定并恢复悬停高亮。旋转视角、缩放或将指针移出预览时，选区仍保持固定。局部、表面、整个部件和边缘模式使用命中点周围的几何。命名区域模式使用已保存的特征位置和标签。模型或放置位置变化时会解除固定。

光标将高斯局部选区限制在所指网格及其连通表面内。表面在开放边缘、材质接缝和至少 35 度的折角处终止；这些是几何区域，不是语义解剖部位。本地控件可选择局部、完整表面、整个网格部件或附近的边界边缘。控件与模型选择器共用圆角玻璃质感，选中项显示为内嵌分段，并提供清晰的键盘焦点。

表面模式导出选中连通表面的所有三角形。整个部件模式导出选中网格的所有三角形。局部模式导出选中表面中与高亮强度非零的局部区域相交的三角形。边缘模式导出选中表面中边界边与该区域相交的三角形。局部与边缘模式导出完整三角形，因此导出的 STL 可能超出可见高亮范围。

查看器为每个显示副本一次性构建几何局部面分块包围盒和表面属性；指针移动每帧最多更新一次 uniform，无需模型调用、主机请求、几何上传或洪水填充。索引在模型加载时准备，不计入稳定状态的拾取延迟。

光标模式位于左下角的紧凑玻璃胶囊中。使用鼠标或触控板时，仅显示当前模式，悬停或键盘聚焦后显示所有选项。触屏控件保持展开，点击区域为 44px。命名区域模式需要区域表。减少透明度或提高对比度时使用不透明背景。

## 高亮诊断

`viewerDiagnosticsDirectory` 默认为 `~/.rumi/viewer-logs`。私有 JSONL 文件记录高亮请求 ID、主机唤醒与状态传递、客户端应用与反馈阶段、文档可见性、视口尺寸、标识比较以及完成耗时。客户端耗时使用单调时钟；主机接收时间用于确定跨进程顺序。不记录模型源码、图像、音频、转录文本或凭据。文件保留到手动删除。日志 I/O 错误会使所属操作失败；客户端诊断传递失败也会报告到浏览器控制台。

`not_rendered` 包含 `reason`：`ack_timeout` 表示没有收到匹配确认，并不能证明高亮未显示；`viewer_hidden` 和 `render_failed` 是渲染器明确报告的状态。隐藏文档恢复可见时会重绘并报告当前高亮。仅高亮更新会复用几何、材质和测量报告，只更改区域 uniform。放置、构建体积和源码变化会使测量失效。CPU 诊断命令 `node --import tsx/esm apps/rumi/brand/print-studio/tests/viewer-highlight.perf.ts` 可通过 `--rebuild` 比较 uniform 更新与重建；它不包含网络、模型响应或 GPU 耗时。

## 编辑与检查期间的渲染

查看器以持续流动的青绿色表面光泽表示智能体正在处理模型，以沿模型上下移动的更亮扫描带表示模型验证。效果复用现有显示几何和一个共享动画时钟，每秒最多绘制 30 次，在隐藏或移出屏幕时暂停，启用减少动态效果时保持静止。处理期间禁用编辑、模型选择和打印操作；仍可旋转视角、缩放、精确指向以及返回模型。工作效果不会出现在项目封面中，也不会改变模型几何。验证结果使用现有的紧凑状态指示器，而不是持续显示文本横幅。

打印预览借用原始几何和材质，暂停悬停叠层而不丢弃已准备的索引，并将拖动绘制合并为每动画帧一次。关闭、替换源或销毁查看器时，先释放预览资源，再释放其源模型。悬停索引使用存储有界的紧凑面分块，同时保留精确三角形和材质接缝。所属模块的[性能测量](../../tests/viewer-hover.perf-results.json)涵盖 CPU 准备、拾取和叠层暂停，不测量 GPU 帧时间或端到端浏览器输入延迟。

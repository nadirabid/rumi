# Analog shaping

Understand the desired result and preserved parts first. Read the current `meshState` context, inspect the original Blender source, and use `viewer_highlight` to establish a deformation region. Cuts instead use the automatic continuous teal line at the actual cut plane; do not approximate the rim with Gaussian blobs. A rendered cut-control result confirms this guide as well as the controls. For bulging, bending, twisting, tapering, or a continuous planar cut, call `viewer_controls` with action `open`. The viewer previews the operation on the existing geometry locally with its original materials; it does not compare two finished models. Read `interactive-controls` and supply labeled control declarations bound to the operation values. Do not generate UI code or rebuild Blender while a person drags.

Supply the exact source path, revision and url, a short plain-language region label, and exact mesh names in `parts` (empty means all meshes in the region). The local frame uses N = direction, U = world-up cross N, V = N cross U. Near a vertical N, world-up is Y instead of Z. `center` is model-local XYZ millimetres; `radii` are extents along U, V, N. Choose a compact region that excludes parts that must stay fixed. Inspect actual geometry, not anatomical guesses. The peak moves within that frame; spread scales the ellipsoid. Influence is compact and zero outside the ellipsoid. The ellipsoid applies only to deformations. Cut uses one continuous plane across all selected parts. These USD adapters do not implement extrusion, curved cuts, remesh, or bevel. Custom parameterized JavaScript models can expose other edits through `interactive-controls`; verify a faithful binding rather than substituting an unrelated operation.

For a continuous bottom cut, choose `operation: cut`, `direction: [0,0,1]` to retain the upper side, and `center` at the proposed cut height in model-local millimetres. `amount` moves the plane by `(amount*2-1)*limit` along direction; .5 is the proposed height. `angle` tilts along V and `spread` leans along U, each spanning -60 to +60 degrees with .5 neutral. Positive tilt raises the plane toward positive V; positive lean raises it toward positive U. `peakX`, `peakY` and `falloff` are unused; supply .5. Set all radii at least as large as limit; radii do not clip the cut footprint. Select every part that should share the edge. Opening a cut clears prior Gaussian highlights and uses a continuous teal cut-line guide that follows the live plane. The guide disappears on freeze or close; other region highlights are rejected until the cut is resolved. The viewer shows the retained side with capped cross-sections; dragging updates uniforms locally. Do not apply a cut first when the person says "let me edit it". Open controls and let them explore. If revising an already applied cut, open the matching earlier revision when they need to lower the edge and restore removed material. The frozen recipe uses an exact Blender intersection to cap cut surfaces while preserving cavity openings.

For deformations, all six `values` are normalized 0..1. Amount .5 is unchanged; values above .5 are positive, below .5 negative. For bulge, `limit` is maximum displacement in mm, no greater than the smallest radius. Spread .5 gives the specified extents; peakX and peakY .5 center the effect. Angle .5 points directly outward. Falloff ranges from broad to concentrated; .35 is a useful initial curve. Start at the current shape (normally amount .5) unless the person explicitly requested an initial change, and explain the region in one short sentence. Wait for `rendered` before saying the controls are ready. The child adjusts analog controls without needing numbers or operation names. Do not demand a confirmation phrase.

Use the current `meshState` context to see the last released values. While controls are open, cursor snapshots and measurements describe no trustworthy deformed selection; close controls before changing the region. A request to change direction, operation, or region replaces the control session using a fresh open call. A request to discard uses close, restores the untouched original, and clears the region highlight.

Open controls are the current unresolved edit. Interpret satisfaction and topic changes from the conversation and the intended result; do not require a save command or special phrase. Keep controls open while the person is still exploring this edit. When the result meets their intent, or they move to another task, preserve the latest visible shape and resolve this edit before proceeding. An explicit cancel or revert instead uses close to discard the preview. Do not claim completion while controls remain unresolved.

To finish, use action `freeze` with the current control ID. This captures their latest live values from the visible viewer, hides the controls and region highlight, retains the shaped preview while saving, and returns a recipePath. If it is not frozen, do not export. Call `blender_status`, open the original .blend corresponding to the selected USD, load the returned helper with runpy, call `helper['apply_shape_controls'](recipePath)`, then `helper['publish']` to save an immutable new revision. The helper verifies the source USD hash and uses the viewer's deformation formula or cut plane in millimetres. It bakes evaluated modifiers on affected parts; preserve the original .blend with its modifier stack. Do not independently approximate the slider values with another Blender operator. Finally viewer_load the exported revision and verify it; the current meshState context must show both analog and highlight cleared before moving on. Failed execution leaves the original untouched on disk; explain the error and allow reopening controls with the saved values. The shape is not certified print-ready.

Every control has an icon reset to its exact neutral value, without changing the others. Strength becomes zero deformation, Spread returns to the supplied region extents, Tilt and Lean return to zero relative to the supplied direction, Height returns to center, Peak resets both coordinates to the center, and Softness returns to its midpoint. These are neutral values (.5), not the agent’s initial tuning. Resets update the preview locally and report the resulting values immediately.

# Rumi 原生设置

[English](README.md) | 中文

Rumi → 设置…（⌘,）打开原版 DSH 设置对话框。Rumi → 插件… 打开原版插件页面。表单、可用选项、存储和校验仍由原版插件负责；此包没有可编辑配置或凭据路由。

Rumi 禁用了导航侧栏。此包在 `shell.overlay` 下声明 `sidebar.settings` 插槽，并在隐藏容器中渲染原版设置外壳。外壳将对话框挂载到文档正文，其未使用的侧栏入口保持隐藏。`settings.launcher` 占用者订阅原生菜单事件并调用外壳自身的 `openSettings` 操作。原版外壳注册键盘快捷键。插件操作关闭已打开的模态窗口并选中现有插件面板。

原生预加载脚本仅在 Rumi 产品源上提供菜单订阅。入口卸载时取消订阅。该集成不提供模型可见输入。

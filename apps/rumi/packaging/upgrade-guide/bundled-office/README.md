# Opening Office files

English | [中文](README.zh.md)

## Change

The packaged Rumi app no longer bundles LibreOffice. Projects that used its previews, file conversions, or spreadsheet recalculation need an external Office application for those operations.

## Migration

Open the original DOCX, XLSX, or PPTX file in a compatible desktop editor. To view a rendered copy in Rumi, export it as a PDF and open that file in the project preview.

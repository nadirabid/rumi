# 打印机与打印布局

[English](README.md) | 中文

在**插件 → 内置插件设置**中打开 Print Studio 卡片，检查 Bambu Studio、H2D 配置和局域网打印机发现状态。主机通过 SSDP 发现打印机；登录后可获取绑定打印机的访问码以监控状态。参见[设置技能](../../skills/print-studio-setup/SKILL.md)和[打印机检查技能](../../skills/inspect-printer/SKILL.md)。

打印机 IP 和序列号存储在 `$DSH_HOME/print-studio/printer.json` 中，仅所有者可访问。局域网访问码通过 `ctx.credentials` 存储为 `BAMBU_LAN_ACCESS_CODE`；它不会返回给客户端，也不会写入配置补丁。

## Bambu 应用安装

在 macOS 上，选择 **Set up Bambu Studio**，即可从 `bambulab/BambuStudio` 的 GitHub 发布安装 Bambu Studio 02.09.01.70。安装器使用固定的 SHA-256 校验和验证通用磁盘映像。暂存的应用必须通过 Bambu 团队 `T3UBR9Y3B2` 的深度代码签名验证和 macOS Gatekeeper 评估。Rumi 将应用安装到 `$DSH_HOME/print-studio/applications`，也识别 `/Applications` 和 `~/Applications` 中的副本。

安装过程报告下载、验证、安装及失败状态。并发请求共用一次安装。安装失败时保留现有副本，重试时重新下载。插件关闭时等待安装和暂存清理完成。磁盘映像卸载失败时保留暂存目录，并报告清理失败。`appDownloadTimeoutSeconds`（900）和 `appDownloadRetries`（2）配置每次下载的网络时限和重试次数。挂载、复制、签名和 Gatekeeper 步骤分别限时 600 秒。更新固定版本时，要更新校验和，并在每个目标平台验证发布者签名和应用启动。

## 账户登录

设置卡片在独立的 Rumi 桌面窗口中打开 Bambu 托管的登录页。桌面适配器只接受该窗口中位于 `https://bambulab.com` 的主框架发送的登录消息。社交登录打开系统浏览器，并通过临时回环监听器返回。关闭窗口、关闭 Rumi 或达到三分钟期限时，会移除监听器和消息处理器。

窗口在用户代理中提供以空格分隔的 `BBL-Slicer/v02.08.02.61` 标记，使 Bambu 页面启用 Studio 票据回调。页面通过 `get_localhost_url` 获得 `http://localhost:<port>` 地址后才打开系统浏览器；Bambu 拒绝数字形式的回环地址。浏览器登录必须保留该返回地址。收到票据后关闭登录窗口，并将焦点移回 Rumi。

Print Studio 验证返回消息，通过 Bambu 的票据端点交换票据，并通过 `ctx.credentials` 存储凭据。桌面适配器不保留令牌或密码。浏览器卡片需要 Rumi 的桌面桥接；独立的 DSH Web 无法打开此原生登录窗口。

托管页面和票据交换已使用真实 Bambu 账户验证；Bambu 更改页面后应重新验证。本地测试覆盖用户代理格式、回调地址、票据传递、窗口清理、消息验证和票据请求。

## 打印监控

`GET /api/print-studio/print/status` 和 `print_studio_progress` 通过本地 MQTT 读取进度、层数、温度、AMS 和错误。

## 打印布局

活动实体部件必须分开打印后组装，并保留声明的旋转或滑动功能。智能体按照[分开打印要求](../../skills/printable-joints/SKILL.md#separate-printing-for-moving-parts)设计可组装的连接结构并说明组装顺序。旧的组装状态打印活动模型仍可查看，但在重新设计前不能发布、通过验证或准备打印。现有模型和脚本参见[迁移说明](../../upgrade-guide/separate-moving-parts/README.zh.md)。

在标准 USD 模型预览中选择 **安排打印**，即可将实体部件放到打印板上。**返回模型** 恢复已保存的模型及其运动控件。分开制造的部件单独放置，包括组装后通过固定连接相连的部件。旧的静态原位打印组保持整体。多部件模型缺少制造声明时，必须先修正模型才能排列。自动排列尝试轴对齐方向，优先降低高度，并在不改变比例的情况下添加打印板。它不选择支撑，也不保证可打印性。

拖动部件调整板上位置。所选部件显示轮廓。**撤销** 保留最多 32 次更改；**自动排列** 重新放置部件。包围矩形重叠、间距不足、超出打印板或过高都会阻止导出。完成编辑后，系统会在项目旁自动为每个模型原子保存独立的摆放信息。保存按顺序执行，并合并排队的编辑；选择部件或打印板不会写入布局。保存失败时保留草稿并提供 **重试保存**。返回模型、切换模型和打开切片软件会等待当前保存完成。保存的布局必须匹配源内容、查看器变换和打印板尺寸；模型更改后提供新排列供检查。无法读取的保存状态保持不变，直到用户明确开始新布局。

**在 Bambu Studio 中打开此板** 将选中的打印板导出为标准 3MF 文件，存放于新的私有 `.rumi-print-*` 项目文件夹。每个可打印部件都是可独立选择的对象，并保留比例、朝向和相对位置。纯色材质按面保存，同一网格可以包含多种颜色。在 Bambu Studio 的颜色导入窗口中将颜色映射到耗材。在 Bambu Studio 2.8.2 中，如果提示仅加载几何数据，请选择**确定**。打印前请检查打印板、支撑和切片。此操作不会发送打印任务。启动失败时保留导出文件，并报告交接状态不确定。`printLayout.gap` 配置部件及边缘间距（默认 5 毫米），`printLayout.volume` 配置备用打印范围（默认 300 × 320 × 320 毫米）；明确设置的场景打印体积优先。

打印板放置检查独立于模型验证。查看器的状态指示器显示所选模型的验证状态。

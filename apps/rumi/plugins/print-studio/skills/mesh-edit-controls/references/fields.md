# Displacement fields


Use `operation: fields` for custom edits that preserve mesh connectivity, such as a local profile adjustment or independently changing a feature’s dimensions. Keep the existing USD loaded and its matching `build123d` source script and STEP/B-Rep revision. Supply exact `parts` names, explicit `controls`, initial zero `values`, and one field per control axis. All ranges must stay within -1..1 and reset to zero. A value of 1 applies the full authored displacement; -1 applies its inverse. Do not label normalized values as millimetres.

Each field contains `key`, `origin`, `spacing`, `dimensions`, and flattened `offsets`. Origin and spacing use model-local millimetres after part transforms, before whole-design placement. Dimensions are 2–16 samples per axis. Store XYZ displacement triples in x-fastest order: `((z * ny + y) * nx + x) * 3`. Offsets describe displacement at value 1, in millimetres, bounded to ±1000 per component. Every boundary sample must be zero; the exterior stays unchanged. The viewer uses trilinear interpolation and sums fields against the original geometry, independent of control order. Up to twelve fields are supported.

For larger lattices, write the array as project-local JSON and pass `fieldsPath` instead of inline `fields`; the tool snapshots the data into the frozen recipe. Generate these arrays with a confined Python script from the intended deformation. Include padding around the edited region and enough samples to represent its curve. Keep protected interfaces outside the field support, or set every lattice node influencing their cells to zero; a zero sample at one point does not keep its neighbors fixed. All fields apply to every mesh in the session’s `parts` list, so exclude fixed parts and check for unintended cross-part influence. Spatially overlapping parts cannot receive different mappings in one field session. Apply compatible fields to joined surfaces and both sides of a shell. Inspect neutral, individual extremes and combined extremes before presenting controls. Field interpolation does not preserve wall thickness, prevent intersections, or implement topology changes. Use the built-in cut for a continuous planar trim; other unsupported geometric or count-dependent changes need the reconstruction path above.

Freeze the controls to capture the recipe JSON under `artifacts/shape-controls/`, then read it with `helper["load_control_recipe"](recipePath)` and `helper["summarize_control_recipe"](recipe)` to inspect the chosen displacements and update the parametric `build123d` dimensions, sketches, lofts, or fillets cleanly in exact B-Rep while preserving mating surfaces and joints.
